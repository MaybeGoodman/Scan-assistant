## 1. 复现

用验收探针的原始输入（`independent_probes.py`、`supplemental_checks.py` 对应段落，仅改目录布局）在 `722ccbd` 上复现，7 项全部按报告描述失败：漏问候选 `passed` 并 final 交付；改图后 final 交付；缺材料 `init` 返回 `awaiting_candidates`；`〔5〕` 候选 `passed`、计数 1/1；分母 2→7 时 `consistency` 返回 ok；偶重根 `roots` 返回 ok 并称“无遗漏”；跨批 `merge` 输出无 `questions`。

## 2. 逐项修复

| 编号 | 根因 | 修改 | 修改后实测 |
|---|---|---|---|
| F01 P1 | `verify()` 只核对小问条目数、编号、依赖和块是否存在，不核对块归属 | `variants.py`：每个块只能属于题干、材料或一个小问，重复引用即失败；每个小问须有文字题面块。`questions.py`：源题同题内题干与小问、小问之间不得共用块 | 验收原输入 `failed`（“块 s1 被 小问 (1)、小问 (2) 重复引用”），通过数 0，不产生学生文件；正常候选两问均出现在聊天与 Word 中 |
| F02 P1 | 冻结与重验只绑定候选 JSON；普通 PNG 无哈希、无复核 | `variants.py`：配图须有 `review.figures` 视觉复核，绑定 PNG／SVG 哈希、`reviewed_by=host_vision`、四项检查全 true；`submit` 冻结图件副本并登记哈希；`deliver` 只用冻结副本，交付前核对冻结副本与原文件，改动、删除或旧台账未冻结均拒绝，且在写任何学生文件之前 | 验收原输入（无复核）提交即 `failed`。补上合格复核后：提交 `passed` → 改图 → 交付被拒，无学生文件。正常交付时 Word 媒体与聊天图片字节等于复核时的字节 |
| F03 P1 | `gate()` 只检查题干和小问块，材料缺块的提示不以 `blocks[n]` 定位而被过滤 | `variants.py gate()`：覆盖题目直接引用及经 `materials` 间接引用的全部块；材料为空也阻断；逐项指出材料／小问与块 id | 验收原输入 `init` 被拒：“共享材料 passage 引用的块 MISSING_PASSAGE 不在文档中”，未建立台账；材料齐全时正常进入生成 |
| F04 P2 | 候选验证没有采用源题的复核门槛 | `variants.py verify()`：对候选题面执行 `review_items()`，含 `〔〕`、`XXX`、未决表达式、`uncertain` 角色、插图占位即失败；交付为草稿时提示不再称“全部达到目标数量” | 验收原输入 `failed`，通过数 0；改正后重提交 `passed`，final 交付 |
| F05 P2 | `consistency()` 只顺序查找普通文本片段并比较图片数量 | `docx_audit.py`：用同一导出器重新导出同一 JSON，逐段比较文字、上下标标记和 OMML 结构签名；给出 `source` 时比较图片字节。`deliver` 与命令行 `--against` 传入 `source` | 验收原输入（分母 2→7）检出并定位第 1 段；分子、指数、根式、离子电荷数值、电荷是否上标、反应条件、表格内公式、段落顺序、替换图片均检出；正确文件 ok |
| F06 P2 | 区间网格扫描依赖变号，偶重根可漏检 | `variant_checks.py roots`：多项式用精确有理系数、平方自由部分与 Sturm 序列计数闭区间内不同实根（端点根单独计入）；非多项式或端点非有理时返回 `None`（不确定） | 验收原输入 `ok=false`（“共有 1 个不同实根，只列出 0 个”）；列出该重根时 true；端点根、区间外根、无理根正确；`1/(x-0.5)`、`sin(x)`、根式返回不确定，候选为 `needs_review` |
| F07 P2 | `merge()` 只合并 blocks 与 figures | `pdf_batches.py`：`commit` 校验批次 `questions`／`materials` 结构；`merge` 按稳定 ID 合并，声明不一致报错并指出批次，补记 `source_spans`，缺块写入 `index_check` | 验收原输入合并后保留 `q跨页` 及两个小问，`source_spans` 记录批 1（stem、s1）与批 2（s2）；跨批阅读题组合并后直接 `variants.py init` 成功；被切断的题被标记且不能生成 |

## 4. 样本

`samples/v1/out/` 保持 1.0.0 构建存档，未重新生成。原因：在本环境完整重建会改写 149 个文件，源页与原题重绘图的 PNG 编码字节发生变化（像素一致），使 1.0.0 时按字节绑定的原题插图复核失效，M02 原题被正确阻断；重新复核全部原题插图超出本次修复范围。构建器已改为附上变式图复核，且仅在重绘出的图与复核时像素完全一致时使用复核过的字节。

## 6. 已知限制

- `roots` 的完整性证明只覆盖有理系数多项式；含参数化无理系数（如 `sqrt(2)*x`）的多项式也按非多项式处理，返回不确定。
- 一致性检查以同一导出器重新导出为期望值，证明的是“Word 与已获准 JSON 一致”，不能发现导出器本身对 JSON 的系统性误译；后者仍靠 Word 实物检查。
- 配图视觉复核由宿主填写，脚本只能核对复核记录与文件哈希绑定、字段完整，不能证明宿主确实看过图。
