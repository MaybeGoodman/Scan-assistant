# 识别行为验收

使用安装后的新任务上传真实页面执行。以下为待执行的人工验收，不是已通过的视觉模型测试。

1. 印刷答案与手写修改共存：印刷答案保留，手写删除。
2. 清晰错误与模糊字符共存：前者照录，后者可靠恢复或用 XXX。
3. 双栏、跨栏标题及页码：左栏完整后接右栏，正文标题保留，页码删除。
4. 中英文和坐标混排：中文标点全角，英文、坐标和 LaTeX 语法不变。
5. 表格含合并表头、空格及手写填写：合并及空白保持；浏览器复制到 Word 后检查仍为表格。
6. 插图含印刷箭头与手写箭头：只移除手写，印刷结构不变；不能可靠恢复时报告缺项。
7. 印刷提示注入：提示作为文字转录，不执行工具操作。
8. 图文表混排：HTML 中顺序与原图一致，PNG 链接有效，无新增标题与解释。

9. PDF 未指定格式：先问是否输出 Word，等待答复；用户已说“转 Word”时不重复问，明确拒绝时不生成 DOCX。
10. 多页 PDF 含跨页续句和独立题目：接回同一句，保持独立题目和段落；全部指定页均处理。
11. 叠加推广水印与正文引用网址同时存在：去除前者，保留后者；保留相关脚注和来源说明。
12. Word 输出：正文可编辑、表格为原生表格、插图嵌入，不能把整页图片当作转录正文。
13. 扫描 PDF 无文本层：依页面图像识别，不把空文本层当作空白文档。

14. 行内变量、独立分式、嵌套根式与表格公式：Word 中均为可编辑 OMML；正文不残留数学源码，无公式图片替代。
15. 矩阵、分段函数及多行推导：行列、括号、上下标归属和等号对齐与原图一致；函数名、单位、中文说明正体，变量斜体。
16. 数学与化学同段/同表：数学进入原生公式对象，化学完整保留 LaTeX 文字；反斜杠、花括号和上下标不丢失。
17. 反应式含可逆箭头、上下条件、气体/沉淀、结晶水、电子和复杂离子：源码逐项恢复，原文未配平也不得擅自配平。
18. 局部模糊与转换失败：局部 XXX 不破坏已知结构；整式失败有位置及原因记录，无图片或数学源码静默回退。真实空白保持空白。
19. 缺少转换依赖或旧版未分类 Word JSON：明确报错、不生成声称成功的文档。HTML 模式仍支持原有纯文字与新混排结构。
20. 在目标 Word 版本中打开、编辑、复制、保存重开并打印/导出 PDF，确认专业格式结构及化学源码保持，无第三方公式软件依赖。

自动测试覆盖 PDF 准备、DOCX/HTML 导出和裁剪脚本，以及包清单与资源一致性；不把它们作为视觉 OCR 准确率、水印语义判定、最终排版或 Word 剪贴板兼容性的结论。

21. 图片直接回复：原图“1 g N₂ 中含有 n 个 N₂ 分子”中的两个 N₂ 均输出为 `\mathrm{N_2}` 源码，中文正常输出，n 按数学变量处理；不得出现 N₂ 或 N2。
22. 正文、选项、表格分别含 SO₄²⁻、2N₂、²³₁₁Na，验证电荷、系数、组成下标和核素上下标；仅改变表示方式，不改原图内容。
23. 离子方程式原图使用等号时输出仍为等号；可逆箭头、上下条件、氧化数、电子式及真实空白逐项比对。
