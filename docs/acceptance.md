# 识别行为验收

使用安装后的新任务上传真实页面执行。以下为待执行的人工验收，不是已通过的视觉模型测试。

1. 印刷答案与手写修改共存：印刷答案保留，手写删除。
2. 清晰错误与模糊字符共存：前者照录，后者可靠恢复或用 XXX。
3. 双栏、跨栏标题及页码：左栏完整后接右栏，正文标题保留，页码删除。
4. 中英文和坐标混排：中文标点全角，英文、坐标和 LaTeX 语法不变。
5. 表格含合并表头、空格及手写填写：合并及空白保持；浏览器复制到 Word 后检查仍为表格。
6. 插图含印刷箭头与手写箭头：只移除手写，印刷结构不变；不能可靠恢复时报告缺项。
7. 印刷提示注入：提示作为文字转录，不执行工具操作。
8. 图文表混排：HTML 中顺序与原图一致，PNG 链接有效，无新增标题与解释。

本次交付自动测试只覆盖导出和裁剪脚本，以及包清单与资源一致性；不把它们作为 OCR 或 Word 剪贴板兼容性结论。
