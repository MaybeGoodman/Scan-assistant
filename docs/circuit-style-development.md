# 电路元件教材画法与标注字体：差异、兼容性与验证（1.1.0）

需求依据：`docs/REQUIREMENTS.md` 第 19.1、25.1 节；样式基准 `docs/style-reference/circuit-sample.png`、`label-font-sample.png`。开发基线为 1.0.1 候选（`c3d7370`）。

## 开发前差异分析

| 需求 | 1.0.1 行为 | 实现位置与方式 |
|---|---|---|
| 19.1 电池 | 长线 ±11、短线 ±6、节间画连线 | `c_battery`：短粗负极＋长细正极等距排列，去掉 `link` 线；线宽 1.0／3.0 |
| 19.1 滑动变阻器 | 44×14，滑片线 13 高、小箭头用 `arrow:end` | 48×12，滑片线从 -30 到 -15，另加 `slider_head` 实心三角形（10 长、6 宽）触及电阻体上边；`p` 端子移到 -30 |
| 19.1 电表 | r=13，无衬线正体字母 15 | r=15.5（灯泡直径 1.3 倍），字母 20 并显式 `style:upright`；电动机同步 |
| 19.1 开关 | 两端实心触点，刀片从左触点中心出发 | 左端空心圆 r=3、无右触点；刀片从圆边出发，断开 28°、长 32，闭合水平；`a` 端子 -19。单刀双掷保留两个触点，转轴同样改为空心圆 |
| 19.1 节点／导线／线宽 | 节点 r=2.5，导线 1.5 | 电路元件与两端均为电路元件或节点的导线统一 1.0，节点 r=2；实验器材及其连线保持 1.5 |
| 25.1 字体 | 无衬线正体（Arial／DejaVu Sans），`font-family` 为无衬线链 | 随包 STIX Two Text（OFL）；`pick_font` 按 style 选 Regular／Italic；SVG 用衬线链并给斜体 run 加 `font-style` |
| 25.1 定体 | 无 | `auto_style`＋`looks_chemical` 自动定体；图元／run 的 `style` 显式覆盖；`label_runs` 比对不含 style |
| 25.1 降级 | 缺字体直接报错或静默换字体 | 衬线链→无衬线回退时 `render` 返回 `font_fallback`，`generate` 记入 attempt，复核模板带标记与说明，`review_candidate` 拒绝 pass，`complete` 写入 block.redraw |

基准图实测：灯泡直径 100 px，电表直径 125 px，线宽 3 px，电池长线 88 px／短线 48 px／线距 24 px，开关转轴圆直径 24 px、刀片长 111 px、角度约 26°，变阻器电阻体 200×50 px、箭头 35×18 px。需求表中"刀片长度约为两端距离的 70%"和"字母高度 55%–65%"与实测不符，已按实测改为"约等于转轴到右端导线距离"和"大写字高 40%–50%"。

## 兼容性决策

- 仅电路类组件与电路导线改线宽，实验装置组件、坐标轴、表盘以及 0.6.0 手写图元场景不变；`Parts` 默认线宽仍为 1.5。
- 端子位置变更（开关 `a`、变阻器 `p`）会影响手写 `via` 坐标的旧场景：导线仍按 hv／vh 自动折线，不会报错，但可能出现斜线或越界，需调整 via。已复核并完成的旧 JSON 与其 PNG 不受影响；旧 attempt 不会被重新渲染。
- `label_box` 改为复用 `layout_label`，画布自适配与实际渲染使用同一套字体与基线，消除了此前两处独立计算的漂移风险。
- `--font` 语义不变：显式字体对全部标注生效且不降级；缺失时仍报错（保留原测试）。
- 字号比例保持 0.7，下标下沉由 0.22 调为 0.25（需求"约 25%"），上标不变。
- 未改需求：化学式自动正体只覆盖可确定模式，O₂ 等需显式 `style:upright`，已写入需求 25.1 与技能参考。
